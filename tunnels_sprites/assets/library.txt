# The order of the figure library.
#
# A bracketed name opens a family; the lines under it are that family's
# figures, in the order the selection knob sweeps them. Sprite ids are handed
# out by reading this file top to bottom, so a family occupies one contiguous
# run of ids and the console needs nothing but the run's start and length.
#
# Every figure in assets/shapes must appear here exactly once, and nothing
# else may: the build fails on either, so a figure dropped in the directory
# has to be placed rather than silently landing at the end of the alphabet.
